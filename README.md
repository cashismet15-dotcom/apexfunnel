# Apex360 — Halı Yıkama Firmaları İçin Reklam & Büyüme Ortağı

Facebook/Instagram reklamlarından gelen halı yıkama firma sahiplerini niteleyen ve ikna eden tek sayfalık statik açılış sayfası (landing page).

## Yapı

- `index.html` — sayfa içeriği
- `css/style.css` — stiller
- `js/script.js` — video oynatma ve form → WhatsApp yönlendirmesi
- `assets/videos` — referans/kanıt videoları (720p, sıkıştırılmış)
- `assets/images` — reklam örneği ve müşteri kanıtı görselleri, video posterleri

## Çalıştırma

Herhangi bir statik dosya sunucusuyla servis edilebilir (framework/derleme gerekmez). Örnek:

```bash
npx serve .
```
